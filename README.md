一句话概括：它的强项是“把一件事做完”，以及“你不在场时继续做”。

## 和 Claude Code 比，谁是更值的那个

这是现在绕不开的对比。两家的价格点完全一样（$20 / $100 / $200），但计量方式相反：

- **Claude Code 按时间限**：五小时滚动窗口加每周上限。每天写两小时代码基本碰不到墙；周六来一场十二小时的重构马拉松，就容易撞。
- **Codex 按积分限**：不看你干多久，看任务多重。一天的小修小补几乎不动额度；一次读遍全仓库的迁移，一口气吃掉可见的一块周配额。

同样 20 美元这一档，第三方限制跟踪工具估计 Claude Pro 每周大约能跑 40 到 80 小时 Sonnet 级别的工作，但 Anthropic 自己的文档把 Pro 描述为适合轻度使用；Reddit 上有个跑了一百小时的对照帖，结论是 ChatGPT Plus 能吸收的日常代理工作量，放到 Claude 那边得 Max 5x（100 美元）才装得下。反例也存在——Codex 的窗口和周上限今年调整过不止一次，“便宜”这个优势需要打个小折扣来看。

质量层面，诚实的答案是“看任务”。Anthropic 的模型在多文件重构和深度理解代码库上口碑更好；一次控制变量的对照测试里，Claude Code 消耗约 19.2 万 token（约 2.5 美元），Codex 消耗约 13.6 万（约 2.04 美元）——Claude 多花了约四成 token，换来的是更分解的架构设计和一次额外的冒烟测试。这约 25% 的成本差值值不值，取决于你在意结果的结构还是账单。

还有两个参考项：Cursor 适合想要“代理焊死在漂亮编辑器里”的人；GitHub Copilot 是团队已经住在 GitHub 里的稳妥默认选择，只是它现在的重任务也开始计量了。

安全这块顺带一提：Codex 的沙箱做在内核层（macOS 用 Seatbelt，Linux 用 Landlock 加 seccomp），分只读、工作区可写、完全访问三种模式，网络默认关闭。如果你的仓库环境里躺着生产凭证，这种内核层的拒绝机制出错时更让人放心。
